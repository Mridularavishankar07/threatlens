🚨 PROBLEM: "Login failed. Please try again."

✅ QUICK FIX (Choose One):

┌──────────────────────────────────────────────────────────┐
│  Option 1: One-Click Fix (Easiest)                      │
└──────────────────────────────────────────────────────────┘

   cd threatlens
   fix-login.bat

   This will automatically:
   • Start MongoDB
   • Seed database
   • Test login
   • Tell you if it worked


┌──────────────────────────────────────────────────────────┐
│  Option 2: Manual Fix                                   │
└──────────────────────────────────────────────────────────┘

   Step 1: Start MongoDB (as Administrator)
   ────────────────────────────────────────
   net start MongoDB


   Step 2: Seed Database
   ────────────────────────────────────────
   cd threatlens/server
   npm run seed


   Step 3: Start Servers
   ────────────────────────────────────────
   Terminal 1: cd threatlens/server && npm run dev
   Terminal 2: cd threatlens/client && npm run dev


   Step 4: Clear Browser Cache
   ────────────────────────────────────────
   Press F12 → Console → Type:
   localStorage.clear()
   location.reload()

┌──────────────────────────────────────────────────────────┐
│  Common Issues                                           │
└──────────────────────────────────────────────────────────┘

   ❌ MongoDB not installed
   → Download from mongodb.com

   ❌ MongoDB not running
   → net start MongoDB (as Admin)

   ❌ Database empty
   → npm run seed (in server folder)

   ❌ Wrong password
   → Use exact: User@123 or Admin@123

   ❌ Port 5000 in use
   → Kill process or change PORT in .env
